# fonts

Subsets of [Latin Modern](https://www.gust.org.pl/projects/e-foundry/latin-modern)
(the OpenType Computer Modern of LaTeX documents), made by `tools/fonts.py`: the
Latin-1 letters, ß and ẞ, and German quotes and dashes. `pdfhooks.mjs` draws
with them the letters a PDF set in Computer Modern lacks (a Swiss document's
fonts have no ß), which hardly any computer has installed otherwise.

which is legally equivalent to the LaTeX Project Public License. These files
are modified (subset), so they carry other names ("HDFX LM Roman", "HDFX LM
Sans", "HDFX LM Mono").
